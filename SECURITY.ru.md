## Что программа делает в системе

Чтобы оценивать риски, полезно знать полный список действий:

| Что | Где | Зачем |
|---|---|---|
| Чтение имён и позиций значков | процесс `explorer.exe`, окно `SysListView32` | узнать, что лежит на столе и где стоит |
| Перебор папок рабочего стола | `%USERPROFILE%\Desktop` и `%PUBLIC%\Desktop` | найти ярлыки, папки и файлы для группировки |
| Чтение реестра | `HKCU\Software\Microsoft\Windows\Shell\Bags\1\Desktop` (`FFlags`) | проверить, включено ли «Упорядочить значки автоматически», и не применять раскладку, если включено |
| Запись позиций значков | те же окна, сообщение `LVM_SETITEMPOSITION32` | расставить значки по блокам |
| Чтение фоновой картинки | файл, выбранный в диалоге | использовать его как основу обоев |
| Запись в реестр | `HKCU\Control Panel\Desktop` (`Wallpaper`, `WallpaperStyle`, `TileWallpaper`) | поставить сгенерированные обои |
| Запись в реестр | `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\DesktopGroups` | запись в списке приложений (только при установке) |
| Файлы | каталог программы: `config.json`, `wallpaper.png`, `backups\` | настройки, обои, бэкап позиций |
| Файлы | `%LOCALAPPDATA%\Programs\DesktopGroups` | каталог установки |
| Ярлыки | меню «Пуск», рабочий стол (по флагу) | запуск и удаление |

Чего программа **не** делает:

- не ходит в сеть — ни проверок обновлений, ни телеметрии;
- не требует и не запрашивает права администратора;
- не устанавливает службы, драйверы, задачи планировщика и автозапуск;
- не читает файлы за пределами рабочего стола и своего каталога
  (плюс та единственная картинка, которую вы выбрали сами);
- не хранит и не запрашивает пароли, токены и ключи;
- не запускает внешние программы.

## Модель угроз

| Актив | Угроза | Как закрыто |
|---|---|---|
| Позиции значков | программа испортит раскладку | бэкап перед применением, проверка после, повторные проходы |
| Реестр | запись в чужие ключи | только два ключа `HKCU`, перечислены выше |
| Память `explorer.exe` | повреждение чужого процесса | выделяется один буфер 4 КБ через `VirtualAllocEx`, освобождается в `finally`; пишутся только `LVITEM`/`POINT`; под 32-битным PowerShell программа отказывается работать, потому что размер структуры не совпал бы |
| `config.json` | подмена файла, мусор в именах групп | значения используются как подписи и имена, а не как код или пути; имена сопоставляются с реальными значками, лишние отбрасываются; цвет и длина проверяются |
| Фоновая картинка | вредоносный или битый файл | файл разбирает `System.Drawing`, размер ограничен 100 МБ, читается в память и освобождается; битый отклоняется и в настройки не попадает |
| Обои | подмена файла обоев | картинка генерируется локально из плана раскладки |

## Как проверить код самому

Всё, что делает программа, видно в четырёх файлах: `DesktopGroups.ps1` (окно),
`lib\Engine.ps1` (логика), `lib\Strings.ps1` (тексты интерфейса) и
`lib\DesktopIcons.cs` (слой P/Invoke, компилируется при старте через `Add-Type`).
Внешних зависимостей нет, весь код в репозитории.

```powershell
# статический анализ
Install-Module PSScriptAnalyzer -Scope CurrentUser -Force
Invoke-ScriptAnalyzer -Path . -Recurse -Settings .\PSScriptAnalyzerSettings.psd1

# проверки без рабочего стола
powershell.exe -NoProfile -File .\tests\check-encoding.ps1
powershell.exe -NoProfile -File .\tests\smoke.ps1
powershell.exe -NoProfile -File .\tests\i18n.ps1

# поиск секретов в истории
git log -p | Select-String -Pattern 'ghp_|api[_-]?key|password\s*=' -CaseSensitive:$false
```

Подробнее об инструментах — в [docs/security-tooling.md](docs/security-tooling.md).

## SmartScreen, подпись кода и почему появляется предупреждение

Microsoft Defender SmartScreen смотрит на два сигнала: **репутацию издателя**
(подписан ли файл и кем) и **репутацию хеша файла** (скачали ли его много людей
без жалоб).

Текущее поведение по документации Microsoft
([SmartScreen reputation](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)):

| Способ распространения | Первая загрузка |
|---|---|
| Microsoft Store | предупреждения нет — Microsoft переподписывает приложение |
| Подпись валидным сертификатом OV/EV | **предупреждение всё равно есть**, пока не накопится репутация; показывается имя проверенного издателя |
| Без подписи или самоподписанный | предупреждение «Windows защитила ваш компьютер» |

Два важных факта:

- **EV-сертификат больше не обходит SmartScreen.** Это перестало работать
  несколько лет назад; платить за EV только ради отсутствия предупреждений
  смысла нет.
- **У неподписанных файлов репутация начинается с нуля на каждой новой версии.**
  Только сертификат подписи переносит репутацию между выпусками.

Про этот проект конкретно: скачивается ZIP с файлами `.ps1`, `.cmd` и `.cs` —
**никакого `.exe` нет**. Поэтому механика «репутации программы» почти не
применяется. Первый запуск ломает другое:

1. ZIP получает *метку «из интернета»*, и Windows может попросить его разблокировать;
2. PowerShell по умолчанию (`RemoteSigned`) отказывается запускать неподписанный
   скачанный скрипт;
3. на Windows 11 с включённым **Smart App Control** неподписанные скрипты могут
   блокироваться полностью, и помогает только отключение этой функции.

### Что делает проект

- `install.cmd` и `DesktopGroups.cmd` передают `-ExecutionPolicy Bypass`
  **только своему процессу**; системная политика не меняется.
- README описывает шаг **«Разблокировать»** и команду `Unblock-File`.
- К релизу прилагаются `SHA256SUMS.txt` и **подписанная аттестация происхождения**,
  чтобы загрузку можно было проверить:

  ```powershell
  gh attestation verify .\DesktopGroups-1.1.0.zip --repo mikel38487/DesktopGroups
  ```

### Что уберёт предупреждение

| Вариант | Стоимость | Подходит проекту? |
|---|---|---|
| **SignPath Foundation** — бесплатная подпись OV-уровня для open source | бесплатно, нужна сборка из публичных исходников | лучший вариант, требуется заявка |
| **Сертификат OV** (Sectigo, Certum, …) | примерно 200–400 € в год, нужен токен или облачный HSM | работает, но репутация всё равно с нуля |
| **Azure Artifact Signing** (бывший Trusted Signing) | от 9,99 $ в месяц, дружит с CI | нужна подтверждённая история бизнеса от 3 лет; физлицам недоступно |
| **Microsoft Store** | бесплатно | не подходит: это скриптовый инструмент, а не упакованное приложение |
| **EV-сертификат** | самый дорогой | для SmartScreen бесполезен |

**Ручной заявки**, которая выдаёт репутацию потребительским устройствам, не
существует — она накапливается сама от объёма загрузок. Администраторы предприятий
могут прислать файл через
[портал Microsoft Security Intelligence](https://www.microsoft.com/en-us/wdsi/filesubmission),
чтобы ускорить доверие в управляемом парке.

## Как сообщить об уязвимости

- Не открывайте публичный issue. Используйте вкладку **Security** →
  **Report a vulnerability** (GitHub Security Advisories).
- Если это невозможно — напишите на адрес из профиля GitHub, без подробностей
  эксплойта в открытом виде.
- Что полезно приложить: версия (`VERSION`), версия Windows, шаги
  воспроизведения, ожидаемое и фактическое поведение.

Сроки: подтверждение получения — до 3 дней, оценка — до 7 дней, исправление —
по договорённости в зависимости от серьёзности.

## Область действия

В зоне внимания: код в этом репозитории, установщик, генерация обоев,
работа с реестром, фоновые изображения и работа с окном рабочего стола.

Вне зоны: уязвимости Windows и Explorer, сторонние темы оформления,
поведение самого рабочего стола при ручном перетаскивании значков.

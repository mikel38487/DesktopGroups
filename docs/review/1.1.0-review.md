# Ревью 1.1.0: два языка и фоновый рисунок

| | |
|---|---|
| Версия | 1.1.0 |
| Дата | 2026-11-10 |
| Объём изменений | `lib\Strings.ps1` (новый), `DesktopGroups.ps1` (переписан под локализацию), `lib\Engine.ps1` (фоновый рисунок, локализованные имена групп), документация на двух языках |
| Метод | чтение кода, замеры вёрстки, пиксельные проверки обоев, автотесты |

## Как проверялось

- **Вёрстка.** Реальная ширина каждой подписи измерена `TextRenderer::MeasureText`
  со шрифтом Segoe UI 9 (и 9 Bold для главной кнопки) и сравнена с шириной
  контролов в коде. 40 сочетаний «контрол × язык».
- **Переводы.** `tests\i18n.ps1`: совпадение наборов ключей ru/en, отсутствие пустых
  строк, наличие всех ключей, которые использует код, подстановка параметров
  (включая ноль), локализация названий групп, смена языка.
- **Строки в обход таблицы.** Поиск присваиваний `.Text = 'литерал'` и вызовов
  `MessageBox` с литералами: не найдено.
- **Фон обоев.** Генерация на белой, серой, чёрной и ярко-зелёной картинке;
  измерение пикселя плашки под подписью и расчёт контраста по WCAG.
- **Ссылки и версии.** Проверка всех относительных ссылок и якорей в `.md`,
  согласованность `VERSION` / `CHANGELOG` / заголовка окна.
- **Пакет.** Состав `dist\DesktopGroups-1.1.0.zip` сверен со списком нужных файлов.
- **Регрессия.** `check-encoding`, `smoke`, `i18n`, фаззинг конфига,
  PSScriptAnalyzer — всё зелёное; smoke и i18n добавлены в CI.

Независимое ревью тремя отдельными агентами было запущено, но прервано по просьбе
владельца (нагрузка мешала работе за компьютером). Ниже — результаты проверок,
выполненных автором; независимое ревью 1.1.0 остаётся открытым пунктом.

## Что осталось открытым

- **Независимое ревью 1.1.0** — не выполнено: агенты остановлены владельцем.
  Проверки выше сделаны автором кода, то есть не независимы.
- **Фоновые рисунки**: не проверены декомпрессионные бомбы (PNG с огромными
  размерами при малом весе) и время генерации на 8000×6000.
- **Многомониторные конфигурации** — по-прежнему не поддержаны.
- **Перезагрузка** — позиции значков сохраняет Windows, отдельного прогона не было.

## Вердикт

Функционально 1.1.0 готова: обе функции работают, регрессий нет, автотесты
и анализатор чистые. Ограничение — отсутствие независимого ревью этого выпуска,
оно отмечено в разделе «Что осталось открытым».

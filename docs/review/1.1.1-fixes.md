# Ответ на ревью 1.1.0 → что вошло в 1.1.1

Три независимых отчёта лежат рядом: `i18n.md`, `background.md`, `docs-release.md`.
Здесь — что из них исправлено, как проверено и что осталось.

Релиз: `v1.1.1` — <https://github.com/mikel38487/DesktopGroups/releases/tag/v1.1.1>

начинаются со значка, это читается лучше заглавной буквы.

## Документация и релиз (docs-release.md: 3 блокера, 7 мажоров)

| Блокер | Решение |
|---|---|
| Обещаны `SHA256SUMS.txt` и аттестация, у v1.1.0 их нет | выпущен v1.1.1 через обновлённый `release.yml`; проверено: `gh attestation verify` → код 0, workflow `release.yml` @ `refs/tags/v1.1.1`, суммы совпадают |
| Удаление сносило `config.json` и папку целиком, документация молчала | `config.json` копируется в `%APPDATA%\DesktopGroups\config-<дата>.json`; портативная копия требует `-Force` и не трогает ярлыки, запись в приложениях и обои; описано в README (en/ru) и guide |
| SECURITY неточен: нет чтения `Shell\Bags`, перебора папок и четвёртого файла | таблица действий дополнена, «три файла» → «четыре файла» с `lib\DesktopIcons.cs` |

Дополнительно: в README добавлен раздел «Ограничения» (только основной монитор и
прочее), в `release.yml` добавлен фаззинг, из `docs/security-tooling.md` убран
пример с версией 1.0.0.

## Что осталось

- Независимая проверка **этих правок** не делалась: ревьюеры работали по 1.1.0.
- Многомониторные конфигурации и перезагрузка — по-прежнему не проверены.
- Подписи кода нет: SmartScreen будет предупреждать до появления сертификата
  (варианты разобраны в `SECURITY.md`).

## Установка

### Обычная установка (без прав администратора)

1. Скачайте `DesktopGroups-<версия>.zip` из раздела Releases и распакуйте.
2. Разблокируйте архив, если Windows пометила его как скачанный:
   правый клик по ZIP → **Свойства** → **Разблокировать**, либо в распакованной папке

   ```powershell
   Get-ChildItem -Recurse | Unblock-File
   ```

3. Запустите `install.cmd`. Он делает четыре вещи:
   - копирует программу в `%LOCALAPPDATA%\Programs\DesktopGroups`;
   - создаёт ярлык `DesktopGroups.lnk` в меню «Пуск»;
   - добавляет запись в списке приложений (`HKCU\...\Uninstall\DesktopGroups`);
   - запоминает текущие обои в `previous-wallpaper.json`, чтобы вернуть их при удалении.

Всё пишется в ваш профиль. Права администратора не нужны.

### Портативный режим

Не запускайте `install.cmd`, а откройте `DesktopGroups.cmd` из распакованной папки.
Программа будет держать `config.json`, `wallpaper.png` и `backups\` рядом с собой.

Не кладите портативную копию в `C:\Program Files`: обычный пользователь туда не
пишет, и программа не сможет сохранить конфиг и обои.

### Удаление

Через «Приложения» в параметрах Windows или `uninstall.cmd` из папки установки.
Программа удаляется, ярлык в «Пуске» исчезает, запись в списке приложений тоже,
а прежние обои восстанавливаются.

## Первый запуск

Окно открывается с группами, уже предложенными по именам ярлыков. К рабочему столу
ничего не применяется, пока вы не нажмёте **Разложить значки и обновить обои**.

При первом запуске рядом с программой создаётся `config.json`. Если файл когда-нибудь
повредится, программа не перезапишет его молча: битый файл переименуется в
`config.bad-<дата>-<время>.json`, а в сообщении будет сказано, куда он уехал.

## Группы

### Предложить группы

**Предложить группы** читает имена значков и заполняет набор по умолчанию: игры,
разработка и AI, связь и интернет, медиа, сеть и VPN, оборудование, установщики,
система и «Прочее» для всего, что не подошло. Программа спрашивает подтверждение,
потому что текущие группы заменяются.

Сравнение идёт по целым словам: `Codecs` не считается словом `code`, а
`Immediate` — словом `media`.

### Свои группы

| Кнопка | Что делает |
|---|---|
| **Новая** | добавляет группу с введённым названием |
| **Переименовать** | меняет название выбранной группы |
| **Удалить** | удаляет группу, её значки уходят в «Прочее» |
| **↑ выше / ↓ ниже** | меняет порядок блоков на обоях |
| **Добавить значки…** | переносит свободные значки в выбранную группу |
| **Убрать из группы** | возвращает выбранные значки в свободные |

Одинаковые названия не принимаются. Пустое название или одни пробелы игнорируются.
Порядок значков в списке группы — порядок, в котором они встанут в блоке.

### Сканировать стол

**Сканировать стол** перечитывает рабочий стол и **не** выбрасывает ваши группы:
исчезнувшие значки убираются из групп, новые попадают в «Прочее», а изменившиеся
имена сопоставляются заново. Так и надо обновлять список после добавления или
удаления ярлыков.

## Язык интерфейса

Переключатель в правом верхнем углу меняет **Русский** и **English** сразу,
без перезапуска. Выбор сохраняется в `config.json`:

```json
{ "language": "ru" }
```

Порядок приоритета: параметр `-Lang` → `config.json` → язык Windows.
Если в `config.json` поля `language` нет, берётся язык самой Windows
(`InstalledUICulture`, то есть на русской Windows будет русский).

Задать язык на один запуск:

```powershell
powershell.exe -STA -ExecutionPolicy Bypass -File .\DesktopGroups.ps1 -Lang en
```

Названия групп — это данные, а не текст интерфейса: смена языка не переименовывает
группы, которые вы создали. Переименовывается только служебная группа «Прочее»/«Misc»,
чтобы обе языковые версии понимали её одинаково.

## Фоновый рисунок

**Фоновый рисунок…** открывает диалог выбора файла (PNG, JPEG, BMP, GIF, WEBP).
**Без фона** возвращает тёмный градиент по умолчанию.

Как используется картинка:

- растягивается на весь экран с **обрезкой по центру** — без искажений и полос;
- сверху накладывается вертикальная тёмная вуаль (плотнее вверху, где подписи);
- рамки рисуются поверх с чуть более заметной заливкой и обводкой, чтобы читались
  на фотографии;
- каждая подпись стоит на своей тёмной плашке и остаётся читаемой на светлых местах.

Файл читается в память и сразу освобождается: программа не держит блокировку.
Его можно потом перенести или удалить — программа просто вернётся к градиенту
и напишет об этом в строке состояния.

Ограничения и защита:

- файлы больше 100 МБ отклоняются с сообщением;
- файл, который не является картинкой, отклоняется и **не** попадает в конфиг;
- если путь перестал существовать, при следующем применении будет градиент.

Путь хранится в `config.json`:

```json
{ "background": "C:\\Картинки\\wall.png" }
```

## Применение раскладки

**Разложить значки и обновить обои** делает по порядку:

1. проверяет, что «Упорядочить автоматически» выключено, и останавливается
   с объяснением, если включено;
2. строит раскладку: каждая группа становится прямоугольником `cols × rows`,
   блоки пакуются в горизонтальные полосы с пустой колонкой между ними;
3. сохраняет текущие позиции значков в `backups\before-apply-<дата>-<время>.json`;
4. расставляет значки через `LVM_SETITEMPOSITION32`, повторяя проходы, пока
   ничего не сдвигается;
5. перечитывает позиции и сообщает, какие значки не встали;
6. рисует обои в размере экрана и применяет их.

Если блоки не влезают на экран, программа сначала спрашивает подтверждение
и помечает предпросмотр предупреждением.

## Бэкапы и восстановление

Каждое применение пишет бэкап всех позиций значков до того, как что-то тронуто.
Хранятся последние 20 бэкапов, более старые удаляются автоматически.

**Вернуть прошлую раскладку** применяет самый свежий бэкап — удобно, если значки
случайно переставились. В бэкапе только позиции, без привязки к группам.

## Файлы и реестр

| Что | Где |
|---|---|
| Программа (установленная) | `%LOCALAPPDATA%\Programs\DesktopGroups` |
| Настройки | `config.json` рядом с программой |
| Сгенерированные обои | `wallpaper.png` рядом с программой |
| Бэкапы | `backups\before-apply-*.json` |
| Обои до установки | `previous-wallpaper.json` |
| Лог ошибки старта | `startup-error.log` (только если окно не запустилось) |
| Настройки обоев | `HKCU\Control Panel\Desktop` (`Wallpaper`, `WallpaperStyle`, `TileWallpaper`) |
| Запись об удалении | `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\DesktopGroups` |

Пример `config.json`:

```json
{
  "groups": [
    { "name": "Игры", "color": "#E0A33E", "items": [ "Steam", "Deadlock+" ] }
  ],
  "language": "ru",
  "background": "",
  "updated": "2026-11-10 01:40"
}
```

Файл пишется атомарно: сначала создаётся временный, затем он переименовывается
поверх старого, поэтому обрыв питания не оставит недописанный конфиг.

## Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| «выполнение сценариев отключено» | политика ExecutionPolicy — Restricted | запускайте `DesktopGroups.cmd` / `install.cmd`, они передают `-ExecutionPolicy Bypass` только своему процессу |
| SmartScreen блокирует программу | подписи кода нет | разблокируйте архив до распаковки |
| Антивирус предупреждает | программа пишет в память `explorer.exe`, чтобы задать позиции значков | это ожидаемо; исходники открыты, записывается только `LVITEM`/`POINT` |
| Рамки не совпадают со значками | после применения менялось разрешение или масштаб | примените раскладку ещё раз |
| Значки переставились сами | включено «Упорядочить автоматически» | выключите и примените заново |
| Фон не виден | файл перенесли или удалили, либо это не картинка | выберите файл снова; текущий фон назван в строке состояния |
| Группы пропали | конфиг повреждён | ищите рядом `config.bad-*.json` и восстановите из него |
| «не найдено на столе: …» | значка с таким именем больше нет | нажмите **Сканировать стол**, имя будет убрано |
| Окно не влезает на экран | маленький экран | окно сжимается до рабочей области и прокручивается |

## Вопросы и ответы

**Программа работает в фоне?**
Нет. Это обычное окно: закрыли — значит её нет. Рамки — часть файла обоев,
поэтому рабочий стол продолжает выглядеть сгруппированным.

**Переживёт ли перезагрузку?**
Да: обои обычные, а позиции значков хранит сама Windows.

**Что если я подвину один значок руками?**
Из своей ячейки уйдёт только он, рамка останется на месте. Нажмите
**Разложить значки и обновить обои**, чтобы перестроить всё.

**Можно поставить свою картинку?**
Да, см. [Фоновый рисунок](#фоновый-рисунок).

**Работает с несколькими мониторами?**
Пока нет: раскладывается только основной монитор.

**Программа что-то отправляет в сеть?**
Нет. Ни проверки обновлений, ни телеметрии.

**Можно править `config.json` руками?**
Да. Некорректные значения чистятся при загрузке: неизвестный цвет заменяется
цветом палитры, слишком длинное имя обрезается, отсутствующее имя значка
отбрасывается.
